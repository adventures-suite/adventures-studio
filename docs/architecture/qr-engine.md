# QR Engine

## Purpose

The QR Engine generates QR code assets for stable public addresses managed by AdventuresSuite.

The QR Engine is a reusable platform capability. It is not limited to destinations and should support any present or future content that can be resolved through the Address Engine.

Examples include:

- Volumes
- Journeys
- Journey segments
- Destinations
- Experiences
- Story sections
- Reflections
- Quotes
- Galleries
- Maps
- Videos
- Audio
- Resources
- Planning views
- Companion views
- Future content types not yet defined

---

## Core Principle

A QR code must encode a stable public address rather than an internal page route.

Example:

```text
https://thesimontonadventures.com/go/acropolis
