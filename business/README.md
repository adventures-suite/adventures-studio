# Adventures Studio Business Foundation

This directory contains the foundational documents that define Adventures Studio.

These documents should evolve slowly.

They are intended to guide product decisions, engineering, marketing, hiring, partnerships, and long-term strategy.

They are not implementation documents.

They describe **why** the company exists, **what** we believe, and **how** we make decisions.
